# Companion skills

Installed next to the GO! Reel Editor by `setup.sh`, so one Claude session can write the copy and build the reel:

- `ez-reel-writer`: writes X-reels, listicles and b-roll reels (on-screen text + caption). Version 2.1, as handed out
  at the GO! "EZ Reels" session (2026-08-12).
- `yap`: turns a rough idea into a yap outline or word-for-word script (claim, hooks, pillars, landing line). As handed
  out at the GO! "Yap" session (2026-08-27).

Setup installs each one into the member's Claude skills folder only when it is missing, or when the copy there was
installed by this editor (it carries a `.from-go-reel-editor` file). A member's own copy is never overwritten.
